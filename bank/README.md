# Банк Erachain

Веб-приложение «интернет-банк» поверх ноды [Erachain](https://github.com/icreator/Erachain_public).
Работает с кошельком ноды через её RPC API: показывает счета и балансы, историю операций,
выполняет переводы активов (ERA, COMPU и любых других) и открывает новые счета.

```
Браузер  ──HTTP──>  bank/server.js (127.0.0.1:8080)  ──RPC──>  нода Erachain (127.0.0.1:9048)
```

Сервер банка — тонкий шлюз без внешних зависимостей (только Node.js ≥ 18):

- раздаёт интерфейс из `public/`;
- открывает сессию по паролю кошелька; пароль хранится только в памяти сервера
  (браузер получает токен, сессия истекает через 15 минут бездействия);
- проверяет входные данные (адрес, сумма до 8 знаков, актив) до обращения к ноде;
- пропускает к ноде только нужные банку методы, а не весь RPC API.

## Возможности

| Раздел        | Что делает                                   | Метод ноды                                   |
|---------------|----------------------------------------------|----------------------------------------------|
| Вход          | проверка пароля кошелька                     | `GET addresses?password=`                    |
| Мои счета     | список счетов и балансы по активам           | `GET addresses`, `GET addresses/assets/{a}`  |
| + Счёт        | открытие нового счёта в кошельке             | `GET addresses/new?password=`                |
| История       | последние 50 операций по счёту               | `GET transactions/address/{a}/limit/50`      |
| Перевод       | перевод актива с назначением и сообщением    | `GET r_send/{from}/{to}?assetKey=&amount=…`  |
| Строка статуса| высота цепочки и режим работы                | `GET blocks/height`, `GET wallet`            |

## Быстрый старт

### Демо (без ноды)

```bash
cd bank
npm run demo          # http://127.0.0.1:8080, пароль: demo12345
```

Демо-режим хранит кошелёк с двумя счетами в памяти — удобно для знакомства и разработки интерфейса.

### С реальной нодой

1. Соберите и запустите ноду Erachain (см. корневой `readme.md`). RPC должен быть включён и доступен
   с локального адреса (`"rpcenabled": true`, `"rpcallowed": ["127.0.0.1"]` в `settings.json`).
   Порт RPC по умолчанию: основная сеть — `9048`, тестовая (`-testnet`) — `9068`.
2. Запустите банк:

```bash
cd bank
ERA_RPC=http://127.0.0.1:9048 npm start
```

3. Откройте http://127.0.0.1:8080 и войдите с паролем кошелька ноды.

Ноду лучше запускать без GUI (`-nogui`): при включённом GUI нода спрашивает подтверждение
каждого RPC-вызова в отдельном окне.

### Переменные окружения

| Переменная  | По умолчанию              | Назначение                         |
|-------------|---------------------------|------------------------------------|
| `ERA_RPC`   | `http://127.0.0.1:9048`   | адрес RPC API ноды                 |
| `PORT`      | `8080`                    | порт веб-приложения                |
| `HOST`      | `127.0.0.1`               | интерфейс для прослушивания        |
| `BANK_DEMO` | —                         | `1` — включить демо-режим          |

## API сервера банка

| Метод и путь                        | Тело / параметры                                         |
|-------------------------------------|----------------------------------------------------------|
| `GET  /api/status`                  | —                                                        |
| `POST /api/login`                   | `{"password": "…"}` → `{"token": "…"}`                   |
| `POST /api/logout`                  | —                                                        |
| `GET  /api/accounts`                | —                                                        |
| `POST /api/accounts`                | — (открыть новый счёт)                                   |
| `GET  /api/accounts/{addr}/history` | `?limit=1..200`                                          |
| `POST /api/transfer`                | `{"from","to","asset","amount","title","message"}`       |

Все методы, кроме `status` и `login`, требуют заголовок `Authorization: Bearer <token>`.

## Безопасность

- По умолчанию сервер слушает только `127.0.0.1`. Если открываете доступ извне — ставьте его за
  HTTPS-прокси (nginx, Caddy): пароль кошелька передаётся при входе.
- RPC ноды наружу не публикуйте: банк — единственная точка входа.
- Перевод в блокчейне необратим — интерфейс всегда просит подтверждение.

```
│   ├── demoBackend.js   кошелёк в памяти для демо-режима

```
